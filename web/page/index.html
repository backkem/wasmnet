    Outcome

      One pcap-ng file per link: open it in Wireshark to see ARP, the TCP handshake and GET /.

      A browser run repeats itself (the same seed gives the same journal and captures), but the order of work inside one instant follows the JavaScript component runtime, so its bytes are not guaranteed to be the native run's; byte-identical runs are a property of the native host.

      The simulator is Rust compiled to WebAssembly; the devices are components transpiled with jco and hosted by codelib-web. Chromium only. Source on GitHub. Third-party notices.
